# TypeScript 7 Type Master

An agentic skill for developing, reviewing, configuring, and migrating TypeScript 7 projects with inference-first, strict, and maintainable type design.

The complete skill is in [`develop-typescript-7/`](develop-typescript-7/). Add or link that directory to the skills location used by your agentic development environment.

The skill covers:

- advanced inference and generic API design;
- definition-driven and schema-driven types;
- `satisfies`, `as const`, type guards, and safe runtime boundaries;
- DRY domain-model composition;
- TypeScript 7 configuration and migration;
- `tsc`, `tsc-watch`, and `tsx` development loops;
- type-level and runtime verification.

Start with [`develop-typescript-7/SKILL.md`](develop-typescript-7/SKILL.md). Supporting references are loaded as needed from [`develop-typescript-7/references/`](develop-typescript-7/references/).
